1.4 Links (ln)
    1.4.1 Hard Links (ln a.txt b.txt)
    	a.txt file have to create or exist first and then use hard link to create b.txt. Everything we do in a.txt is directly effect and change in b.txt too. But we delete or remove a.txt, a.txt is removed without effect or deleting b.txt too, b.txt remains.
    1.4.2 Forcing a Link ([-f]> ln -f a.txt b.txt)
    	If the source file already exists you will get an error,
    1.4.3 Symbolic Links ([-s]> ln -s a.txt b.txt)
